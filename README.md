One haiku about debugging, in the 5-7-5 syllable shape — a breakpoint,
a cursor blinking at three in the morning, and a last line that turns
the poem back on the debugger.

Entry for the [make.fun competition "Seventeen Syllables of Debugging"](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

## Run

```sh
python3 main.py
```

Writes the haiku to `/output/entry.txt` (3 lines, 75 characters).
